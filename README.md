TigerQuant V7 is a high-frequency/swing quantitative trading system designed for the US stock market. Built on the Tiger Trade OpenAPI, it features a pure asynchronous architecture (Asyncio Queue), a built-in 6-dimensional multi-factor scoring model, and dynamic Kelly criterion position management, aiming to provide institutional-grade execution efficiency and risk control capabilities.

TigerQuant V7 是一个专为美股市场设计的高频/波段量化交易系统。基于 Tiger Trade OpenAPI 构建，采用纯异步架构 (Asyncio Queue)，内置六维多因子打分模型与动态凯利仓位管理，旨在提供机构级的执行效率与风控能力。

## 🚀 Core Architecture & Features | 核心架构与特性

* **⚡ Async High-Concurrency Base (异步高并发底座)**: 
  Abandons traditional synchronous blocking in favor of `asyncio` producer-consumer queues, supporting high-throughput data fetching and concurrent order routing for 100+ selected tickers simultaneously.
  *摒弃传统同步阻塞，采用 `asyncio` 生产者-消费者队列，支持对 100+ 只精选标的同时进行高吞吐量的数据抓取与并发订单路由。*

* **🧠 6D Multi-Factor Alpha Scoring (六维多因子打分)**: 
  An original 6-dimensional evaluation system (Technical, Capital, Fundamental, Sentiment, Macro, AI Machine Learning) that calculates a comprehensive score of 0-100 via dynamic weighting.
  *独创六维评估体系（技术面、资金面、基本面、情绪面、宏观面、AI 机器学习），通过动态权重计算输出 0-100 综合得分。*

* **🛡️ Dynamic Risk & Capital Management (动态风控与资金管理)**:
  * **Kelly Sizing (凯利公式动态调仓)**: Dynamically calculates the optimal capital allocation per trade based on win rate and profit/loss ratio. *(根据胜率与盈亏比动态计算单笔最佳下注资金。)*
  * **ATR Trailing Stop Loss (ATR 追踪止损)**: Dynamically calculates the defense line from the highest price after position entry based on Average True Range (ATR). *(基于真实波动幅度 ATR，从建仓后的最高价动态计算防守线。)*
  * **MTF Resonance (多周期共振)**: Forces a 15-minute (15m) bottom-fishing confirmation after a daily signal is triggered to filter out false breakouts. *(日线触发信号后，强制进行 15 分钟级别止跌确认，过滤虚假突破。)*
  * **Macro Regime (宏观避险)**: Real-time monitoring of SPY moving averages. Automatically locks entry permissions when the broader market enters a `RISK_OFF` state. *(实时监控 SPY 均线状态，大盘进入 `RISK_OFF` 状态时自动锁定建仓权限。)*

## ⚙️ Quick Start | 快速启动

### 1. Environment Setup (环境配置)
We recommend using a Conda isolated environment to avoid dependency conflicts:
推荐使用 Conda 隔离环境以避免依赖冲突：
```bash
conda create -n tiger_env python=3.9
conda activate tiger_env

# Install dependencies / 安装依赖
pip install -r requirements.txt

```

### 2. Credential Sanitization & Configuration (凭证脱敏与配置)

This project strictly separates code from privacy. Please save your Tiger Trade OpenAPI private key as `tiger_private_key.pem` in the root directory.
本项目严格分离代码与隐私。请将您的 Tiger Trade OpenAPI 私钥保存为根目录下的 `tiger_private_key.pem`。

Copy the configuration template and fill in your information:
复制配置模板并填入您的信息：

```bash
cp config.example.ini config.ini

```

Fill in your `tiger_id` and `account_id` in `config.ini`, and set `sandbox = True` for paper trading testing.
在 `config.ini` 中填入您的 `tiger_id` 和 `account_id`，并设置 `sandbox = True` 进行模拟盘测试。

> **⚠️ WARNING / 警告**:
> Never commit your real private key (`.pem`) and configuration file (`config.ini`) to a remote open-source repository! Ensure they are added to your `.gitignore` file before committing.
> 切勿将真实的私钥 (`.pem`) 与配置文件 (`config.ini`) 提交至远程开源仓库！请确保在提交前已将它们加入 `.gitignore` 文件。

### 3. Ignition (点火运行)

After configuration, launch the core terminal engine directly:
配置完成后，直接启动核心终端引擎：

```bash
python pro_terminal.py

```
